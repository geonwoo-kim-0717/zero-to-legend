# Zero to Legend 개편 설계 (0단계)

뱀서라이크(시간 생존 + 자동 공격)에서 **트윈스틱 로그라이트 + 2인 협동**으로 바꾸는 설계.
참고: 사용자가 공유한 ChatGPT 대화("로그라이크 멀티플레이 전환")와 지금 코드(Phaser 3 + TypeScript, 웹).

표시: **[확정]** 사용자가 정함 · **[제안]** 제 안, 확인 필요 · **[질문]** 아직 정해야 함

---

## 1. 확정 사항

| 항목 | 결정 |
|---|---|
| 판 구조 | **[확정]** 경로·방 선택으로 변경 (전투·상점·이벤트·보스 방) |
| 조작 | **[확정]** 트윈스틱, 마우스 조준. 주무기 + 보조무기를 직접 조준해 발사 |
| 멀티 | **[확정]** 방장 방식(한 플레이어 브라우저가 게임을 계산), 서버비 없이 |
| 멈춤 규칙 | **[확정]** 레벨업 등 선택 화면은 둘 다 멈추고, 둘 다 선택을 끝내면 재개 |
| 우선순위 | **[확정]** 빌드 확장·장비칸 재구성 먼저 |
| 모드 | **[확정]** 싱글 + 협동 2인 |
| 캐릭터 | **[확정]** 1명으로 축소, 외형 커스터마이징(색상, 성별) |

## 2. 조작 (트윈스틱)

**[제안] PC**
- 이동: WASD
- 조준: 마우스 (캐릭터가 커서를 봄)
- 주무기: 왼쪽 클릭 (누르고 있으면 연사)
- 보조무기: 오른쪽 클릭 (재사용 대기·충전 횟수)
- 대시: Space / Shift
- OS 능력: Q (지금 특수 능력 자리)

**[질문] 모바일**: 지금은 모바일·안드로이드 앱도 배포 중. 트윈스틱으로 바꾸면 모바일은
- (a) 왼쪽 이동 스틱 + 오른쪽 조준 스틱(누르면 주무기 발사) + 보조무기·대시 버튼, 조준 보조 약간
- (b) 모바일 지원 중단(PC 웹 전용)
중 무엇으로 할지.

## 3. 무기: 주무기 6 + 보조무기 6

기존 12종을 그대로 살려 둘로 나눔. 레벨 1~8, 등급 5단계, 전설·신화 능력은 유지.
바뀌는 점은 "가까운 적 자동 조준" → "커서 방향 발사".

**[제안] 주무기 (왼쪽 클릭, 연사)**

| 무기 | 지금 | 트윈스틱으로 |
|---|---|---|
| 스마트 피스톨 | 가까운 적 유도탄 | 커서 방향 연사, 약한 유도 (기본 무기) |
| 스캐터 샷건 | 산탄 7발 부채꼴 | 커서 방향 산탄, 넉백 |
| 레일건 | 체력 높은 적에게 관통 빔 | 커서 방향 충전 관통 빔 (누르고 있다가 놓기) |
| 맨티스 블레이드 | 바라보는 방향 베기 | 커서 방향 근접 베기 연타 |
| 모노와이어 | 가까운 적 방향 채찍 | 커서 방향 긴 채찍, 맞은 적 1초 아군화 |
| 아크 코일 | 가까운 적에게 연쇄 번개 | 커서 쪽 첫 적에게 번개 → 연쇄 |

**[제안] 보조무기 (오른쪽 클릭, 재사용 대기 또는 충전 횟수)**

| 무기 | 트윈스틱으로 |
|---|---|
| 플라즈마 유탄 | 커서 위치에 던져 범위 폭발 |
| 마이크로 미사일 | 커서 근처 적들에게 유도 미사일 일제 발사 |
| 근접 지뢰 | 커서 위치에 지뢰 설치 |
| 포탑 배치 | 커서 위치에 포탑 설치 |
| 해킹 드론 | 드론 발사 → 커서 쪽 적을 일정 시간 공격 |
| EMP 필드 | 커서 위치(또는 자기 주변)에 감속 전자기장 |

**[질문]** 이 나눔이 괜찮은지. 그리고 드론·EMP처럼 "주위를 도는 자동 공격"을 완전히 없애도 되는지 (사이버웨어·OS 쪽 자동 효과로 옮길 수도 있음).

## 4. 장비칸 재구성

지금: 무기 최대 6 + 패시브 최대 6 (레벨업 카드로 획득) + 러너별 특수 능력 1.

**[제안] 새 장비칸 8칸**

| 칸 | 수 | 들어가는 것 | 기존에서 |
|---|---|---|---|
| 주무기 | 1 | 위 6종 | 무기 |
| 보조무기 | 1 | 위 6종 | 무기 |
| OS | 1 | 전투 규칙 + Q 능력 | 특수 능력 4종(뉴럴 오버클럭·광전사·광학 위장·궤도 폭격)을 OS로 |
| 사이버웨어 | 3 (신경·안구·골격) | 상시 강화 | 패시브 4종(강화 근섬유·신경 가속·피하 장갑·자석)을 나눠 넣고 늘림 |
| 장비 | 2 (방어·전술) | 생존·보조 | 새로 만듦 |

- **레벨업 카드는 유지 [확정]**: 고르는 대상이 "새 무기 추가"에서 "장착한 무기·사이버웨어·장비 강화 + 능력치 + 특수 카드"로 바뀜. 장착하지 않은 것의 카드는 안 나옴.
- **아이템 획득 [제안]**: 방 보상(3개 중 1개), 상점(판 안 재화), 엘리트·보스 보상. 칸이 차 있으면 바꿀지 선택.
- **태그·시너지 [제안]**: 아이템마다 태그(전기·화염·관통·근접·폭발·드론 등). 같은 태그 2·3·4개에 단계별 보너스 + 특정 조합 시너지 몇 개. 처음엔 태그 6~8개, 시너지 10개 정도.
- **처음 만들 양 [제안]**: OS 4 (기존 특수 능력 확장), 사이버웨어 9 (부위별 3), 장비 8, 시너지 10.

**[질문]**
- OS를 판 시작에 고르고 고정할지, 판 중에 바꿀 수 있게 할지 (ChatGPT 추천은 판 중 교체 가능).
- 무기 교체: 판 중 다른 주무기를 얻으면 바꿔 끼우는 방식이 맞는지 (지금처럼 여러 개를 동시에 들지 않음).

## 5. 판 구조 (경로·방 선택)

**[제안]** 챕터 3개(하층가 슬럼·인더스트리얼·타워)와 보스 6종은 유지. 챕터마다 갈림길 지도를 고르며 진행.

```
시작 → [전투] → (갈림길) [전투]/[이벤트] → [상점]/[엘리트] → [전투] → [휴식] → [중간보스]
     → [전투]/[보물] → [엘리트] → [상점] → [보스] → 다음 챕터
```

| 방 | 내용 | 기존 자산 |
|---|---|---|
| 전투 | 웨이브 클리어(정해진 수 처치 또는 60~90초 생존) | 지금 적·스폰 디렉터 |
| 엘리트 | 블랙 실드 분대·카운터 몬스터 | 블랙 실드 습격, 카운터 |
| 상점 | 판 안 재화로 아이템·회복 구매 | 블랙마켓 |
| 이벤트 | 진의 의뢰·선택지 | 진 대화 |
| 휴식 | 리퍼닥 수리(회복) 또는 강화 | 클리닉 |
| 보물 | 아이템 상자 | - |
| 중간보스·보스 | 지금 보스 그대로 | 코박·바실리·그레고르·XM-4·노라·센서스 |

**[질문]** 전투방 클리어 조건(처치 수 / 시간 / 둘 중 하나), 챕터당 방 수(제안 10~12개, 한 판 25~35분).

## 6. 캐릭터 1명 + 외형

- **[확정]** 러너 4명(제로·바이퍼·고스트·노바) → 1명. 개성은 OS·장비로.
- **[제안]** 외형: 성별 2종(남·여) × 색상 팔레트(옷·머리·사이버웨어 빛 색 3곳, 각 6~8색).
  - 색은 그림을 다시 그리지 않고 코드로 바꿈(팔레트 교체).
  - 성별은 그림이 2벌 필요: 걷기·대시·피격·쓰러짐 + 주무기 6종 조준 자세.
- **[질문]** 기본 캐릭터를 지금 러너 중 누구 그림으로 할지, 아트 세션에 맡길지.
- 기존 저장 데이터: 러너 해금·크레딧 → 외형 해금·영구 강화로 옮김 [제안].

## 7. 협동 2인 (방장 방식)

- **연결 [제안]**: 브라우저끼리 직접 연결(WebRTC). 처음 연결을 이어 주는 신호 교환은 **이미 쓰고 있는 Supabase**(리더보드용)로 → 추가 서버비 없음.
  - 위험: 일부 회사·통신사 네트워크에서는 직접 연결이 막혀 중계 서버(TURN)가 필요함. 무료 중계는 느리거나 제한이 있음. 실패하면 "연결 안 됨" 안내.
- **방 만들기**: 방장이 방 코드(6자리) 또는 초대 링크 → 친구가 입력.
- **계산**: 방장 브라우저가 적·보스·탄·보상을 모두 계산, 손님은 입력만 보내고 상태를 받아 그림.
- **멈춤 [확정]**: 레벨업·보상·상점 화면은 둘 다 멈춤, 둘 다 끝내야 재개. 상대 선택 중이면 "동료 선택 중" 표시.
- **[제안] 협동 규칙**
  - 경험치: 둘 다 같이 받음. 레벨업은 각자 카드 선택.
  - 재화·아이템 보상: 각자 따로(뺏기 없음).
  - 쓰러짐: 동료가 옆에 3초 서 있으면 부활. 둘 다 쓰러지면 판 종료.
  - 2인일 때 적 체력 ×1.6, 적 수 ×1.4, 보스 체력 ×1.7 (테스트로 조정).
  - 카메라: 각자 자기 캐릭터를 따라감. 둘이 화면 밖으로 너무 벌어지지 않게 거리 제한.
- **[질문]** 오버클럭(슬로 모션)·배속·보스 클로즈업은 둘 모두에게 같이 적용해도 되는지 (제안: 같이 적용, 배속은 방장이 정함).
- 방장이 나가면 판 종료 (방장 방식의 한계, 사용자 확인함).

## 8. 작업 순서

빌드 확장을 먼저 하되, 새로 짜는 코드는 처음부터 "플레이어 여러 명"을 전제로 만들어 나중에 멀티를 붙일 때 다시 짜지 않게 한다.

| 단계 | 내용 | 끝 기준 |
|---|---|---|
| 1 | **조작 전환**: 트윈스틱(마우스 조준), 주무기·보조무기 2칸, 무기 12종 조준형으로 수정 | 싱글로 한 챕터 플레이 가능 |
| 2 | **장비칸 재구성**: OS·사이버웨어 3·장비 2, 레벨업 카드 재편, 태그·시너지 | 빌드에 따라 전투 방식이 달라짐 |
| 3 | **캐릭터 1명 + 외형 선택**(색상 먼저, 성별 그림은 아트 오면) | 아지트에서 외형 고르고 시작 |
| 4 | **판 구조**: 갈림길 지도, 방 종류, 상점·이벤트·휴식, 보상 | 챕터 1을 방 단위로 끝까지 |
| 5 | **게임 로직 분리**: GameScene(6,133줄)에서 계산과 그리기 분리, 플레이어 배열, 시드 무작위 | 화면 없이도 판이 돌고 기존과 같게 플레이 |
| 6 | **한 화면 2인**(두 번째는 키보드·봇)으로 협동 규칙 검증 | 둘이서 챕터 1 클리어 |
| 7 | **온라인 2인**(방장 방식, Supabase 신호 교환) | PC 두 대로 같은 판 진행 |
| 8 | 밸런스·플레이테스트, 저장 데이터 이전, 배포처별 확인 | 출시 후보 |

- 각 단계는 별도 브랜치에서 하고, 지금 버전은 main에 그대로 둠.
- 1~4단계는 싱글로 바로 플레이테스트 가능. 5~7단계는 화면상 변화가 적고 오래 걸림(몇 주).

## 9. 필요한 것

- **아트**: 캐릭터 1명 × 성별 2 × (걷기·대시·피격·쓰러짐·조준 자세), 주무기 6종 손에 든 그림, OS·사이버웨어·장비 아이콘(약 25개), 갈림길 지도·방 아이콘, 2P 표시.
- **기획 표**: 태그 목록, 사이버웨어 9 / 장비 8 / 시너지 10 수치 (초안은 제가 만들 수 있음).
- **테스트**: 협동은 PC 두 대(또는 PC+다른 네트워크) 필요. 실제 지연은 사용자 확인.
- **비용**: 없음 (Supabase 무료 범위, GitHub Pages). 중계 서버가 꼭 필요해지면 그때 다시 결정.

## 10. 남은 질문 (요약)

1. 모바일: 가상 스틱 2개로 유지 / 중단
2. 무기 주·보조 나눔(3절)이 괜찮은지, 자동으로 도는 공격(드론·EMP) 처리
3. OS: 판 시작에 고정 / 판 중 교체
4. 전투방 클리어 조건, 챕터당 방 수
5. 기본 캐릭터 그림(기존 러너 중 누구) / 새로 그림
6. 오버클럭·배속·보스 클로즈업을 협동에서 둘 다에게 적용해도 되는지
7. 블랙 실드 습격·카운터 몬스터·진 대화·히트(난이도)·계약은 유지하는지
