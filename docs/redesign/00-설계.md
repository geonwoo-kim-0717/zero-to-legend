# Zero to Legend 개편 설계

뱀서라이크(시간 생존 + 자동 공격)에서 **트윈스틱 로그라이트 + 2인 협동**으로 바꾸는 설계.
참고: 사용자가 공유한 ChatGPT 대화("로그라이크 멀티플레이 전환")와 지금 코드(Phaser 3 + TypeScript, 웹).

표시: **[확정]** 사용자가 정함 · **[제안]** 확인 필요 · **[질문]** 아직 정해야 함

배포: 개편 작업은 별도 브랜치에서. **사용자가 요청할 때까지 배포하지 않음** [확정]. 지금 버전은 main에 그대로.

## 1. 확정 사항 한눈에

| 항목 | 결정 |
|---|---|
| 판 구조 | 경로·방 선택 (전투·엘리트·상점·이벤트·휴식·보물·보스) |
| 전투방 클리어 | 처치 수 |
| 조작 | 트윈스틱. PC는 WASD + 마우스 조준, 모바일은 가상 스틱 2개 |
| 무기 | 주무기 1 + 보조무기 1, 직접 조준 |
| 자동 공격 무기(드론·EMP 등) | 없애지 않음. 무기·사이버웨어·장비 간 시너지 추가 |
| OS | 판 시작 후 **리퍼닥 조우 이벤트**에서 변경 가능 |
| 멀티 | 방장 방식, 서버비 없음. 싱글 + 협동 2인 |
| 멈춤 | 고르는 화면은 둘 다 멈추고, 둘 다 끝내야 재개 |
| 시간 효과 | 오버클럭 슬로 모션·배속·보스 클로즈업은 둘 다에게 같이 적용 |
| 캐릭터 | 1명 + 외형(색상·성별). 그림은 아트 세션에 새로 의뢰: 8방향 이동, 공격 동작 |
| 기존 요소 | 블랙 실드 습격·카운터 몬스터·진 대화·히트·계약 **유지하되 개편** |
| 우선순위 | 빌드 확장·장비칸 재구성 먼저 |

## 2. 조작 (트윈스틱)

**PC [확정 방향 / 키 배치 제안]**
- 이동 WASD, 조준 마우스(캐릭터가 커서를 봄)
- 주무기: 왼쪽 클릭(누르고 있으면 연사)
- 보조무기: 오른쪽 클릭(재사용 대기·충전 횟수)
- 대시: Space / Shift, OS 능력: Q

**모바일 [확정]**: 왼쪽 이동 스틱, 오른쪽 조준 스틱(누르고 있으면 주무기 발사), 보조무기·대시·OS 버튼. 조준 보조 약간 [제안].

## 3. 무기: 주무기 6 + 보조무기 6

기존 12종을 둘로 나눔. 커서 방향으로 발사.

| 주무기 (왼쪽 클릭) | 트윈스틱으로 |
|---|---|
| 스마트 피스톨 | 커서 방향 연사, 약한 유도 |
| 스캐터 샷건 | 커서 방향 산탄, 넉백 |
| 레일건 | 커서 방향 충전 관통 빔 |
| 맨티스 블레이드 | 커서 방향 근접 베기 |
| 모노와이어 | 커서 방향 채찍, 맞은 적 1초 아군화 |
| 아크 코일 | 커서 쪽 첫 적에게 번개 → 연쇄 |

| 보조무기 (오른쪽 클릭) | 트윈스틱으로 |
|---|---|
| 플라즈마 유탄 | 커서 위치에 던져 범위 폭발 |
| 마이크로 미사일 | 커서 근처 적에게 유도 미사일 일제 발사 |
| 근접 지뢰 | 커서 위치에 지뢰 설치 |
| 포탑 배치 | 커서 위치에 포탑 설치 |
| 해킹 드론 | 드론 발사 → 일정 시간 주위를 돌며 공격 (자동 공격 유지) |
| EMP 필드 | 커서 위치 또는 자기 주변 감속 전자기장 (자동 피해 유지) |

**[제안]** 주·보조 나눔은 위와 같이 하고 1단계에서 플레이로 검증.

|---|---|---|---|

## 5. 성장 시스템 [확정]

원칙: **아이템은 "무엇을 쓸지", 레벨업 카드는 "얼마나 강하게".**

### 5-1. 판 안: 강화 (레벨업 카드)
- 레벨업 카드는 **장착한 것만 강화**. 새 아이템은 카드로 나오지 않음. [확정 1A]
- **레벨은 소켓에 붙음** (무기 소켓 Lv1~8, 장비 소켓 Lv1~5). 아이템을 바꿔 끼워도 소켓 레벨은 그대로 → 새 아이템도 같은 레벨로 시작. [확정 1A, 2A]
- 사이버웨어도 카드로 레벨을 올림. [확정 4C]
  - **[질문]** 사이버웨어도 "소켓 레벨"(바꿔 끼워도 유지)로 할지, 사이버웨어 자체 레벨로 할지. 제안: 다른 소켓과 같이 소켓 레벨.
- 카드 종류 [제안]: 소켓 강화 카드(주무기·보조무기·사이버웨어·장비), 능력치 카드(체력·이동·피해 등), 특수 카드(시너지를 돕는 효과).

### 5-2. 판 안: 빌드 (아이템)
- 얻는 곳: 방 보상(3개 중 1개), 상점, 엘리트·보스 보상. 소켓이 차 있으면 바꿀지 선택.
- **아이템 등급**: 일반·희귀·영웅·전설·신화. 등급이 높을수록 기본 성능이 높음. [확정 3]
- **전설·신화 능력은 아이템 등급에 딸려 옴**: 전설 등급 무기를 얻으면 그 무기의 전설 능력 중 하나가 무작위로 붙어 있음, 신화 등급이면 신화 능력. [확정 3]
  - 지금처럼 레벨업 카드로 능력을 얻는 방식은 없어짐.
  - **[질문]** 신화 등급 무기는 전설 능력 + 신화 능력 둘 다인지, 신화 능력만인지. 제안: 둘 다(전설 1 + 신화 1).
  - **[질문]** 사이버웨어·장비에도 전설·신화 등급과 능력을 둘지. 제안: 등급은 두되 능력은 무기만, 사이버웨어·장비는 등급만큼 수치가 높아짐.
- **리퍼닥 조우 이벤트** [확정 3, 4C]: OS 교체, 사이버웨어 설치·교체, 아이템 등급 올리기(판 안 재화 사용).

### 5-3. 재화 [확정 5A]
- **판 안 재화(가칭 "칩")**: 처치·방 보상으로 얻고 상점·리퍼닥에서 씀. 판이 끝나면 사라짐.
- **크레딧**: 판이 끝나면 쌓이고 아지트에서 씀.

### 5-4. 판 밖 성장 [확정 6A]
- **무기·장비는 처음부터 모두 해금** (판 안 보상에 다 나옴).
- **해금 대상**: 사이버웨어, OS, 시작 주무기 선택, 외형(색·성별·의상).
  - 지금의 러너 해금은 없어지고 이 해금으로 바뀜.
- **클리닉 영구 능력치는 지금보다 약하게** 유지. [확정]
  - **[제안]** 단계별 효과를 지금의 절반 정도로 하고, 최대 단계 수 유지. 수치는 2단계 끝날 때 플레이로 조정.

### 5-5. 시너지 [확정 7A]: 태그 단계 + 이름 붙은 조합
- **태그 6개로 시작 [제안 목록]**: 전기, 폭발, 정밀(관통·치명), 근접, 기계(드론·포탑), 해킹(아군화·교란).
- 무기·사이버웨어·장비·OS 모두 태그를 가짐. 8칸에서 같은 태그가 **2·3·4개** 모이면 단계별 효과.
  - 예: 전기 2 → 감전 피해 증가, 전기 3 → 감전된 적이 죽을 때 연쇄 번개, 전기 4 → 연쇄 횟수 +2
- **이름 붙은 조합 약 10개 [제안]**. 예:
  - 해킹 드론 + 신경 사이버웨어 → 드론이 해킹한 적이 잠깐 아군
  - EMP 필드 + 방어 장비(쉴드) → 쉴드가 깨지면 EMP 폭발
  - 레일건 + 안구 사이버웨어 → 표식된 적에게 관통 피해 증가
  - 포탑 + 전술 장비(드론 도킹) → 포탑 수 +1
- **[제안] 처음 만들 양**: OS 4(기존 특수 능력 확장), 사이버웨어 9(부위별 3), 장비 8, 이름 붙은 조합 10.

## 6. 판 구조 (경로·방 선택)

챕터 3개(하층가 슬럼·인더스트리얼·타워)와 보스 6종 유지. 챕터마다 갈림길 지도.

```
시작 → [전투] → (갈림길) [전투]/[이벤트] → [상점]/[엘리트] → [전투] → [리퍼닥] → [중간보스]
     → [전투]/[보물] → [엘리트] → [상점] → [보스] → 다음 챕터
```

| 방 | 내용 | 기존 자산 |
|---|---|---|
| 전투 | **처치 수를 채우면 클리어** [확정] | 지금 적·스폰 디렉터 |
| 엘리트 | 블랙 실드 분대·카운터 몬스터 (개편) | 블랙 실드 습격, 카운터 |
| 상점 | 칩으로 아이템·회복 구매 | 블랙마켓 |
| 이벤트 | 진의 의뢰·선택지 (개편) | 진 대화 |
| 리퍼닥 | OS 교체·사이버웨어 설치·등급 올리기 [확정] | 클리닉 |
| 보물 | 아이템 상자 | - |
| 중간보스·보스 | 지금 보스 그대로 | 6종 |

- 히트(난이도)·계약은 유지하되 새 판 구조에 맞게 개편 [확정].
- **[질문]** 챕터당 방 수. 제안: 10~12개(한 판 25~35분).

## 7. 캐릭터 1명 + 외형

- 러너 4명 → 1명. 개성은 OS·장비로. [확정]
- 외형: 성별 2종 × 색상 팔레트(옷·머리·사이버웨어 발광 3곳). 색은 코드로 바꿈(팔레트 교체). [제안]
- 그림: 아트 세션에 새로 의뢰 [확정] — 8방향 이동·대시·피격·쓰러짐, 공격 동작(총류는 무기 겹 교체, 근접은 휘두르기). 요청 전달함.
- 그림이 오기 전에는 지금 주인공 그림을 임시로 씀.

## 8. 협동 2인 (방장 방식)

- 연결: 브라우저끼리 직접 연결(WebRTC). 처음 신호 교환은 리더보드용으로 이미 쓰는 Supabase로. 추가 서버비 없음.
  - 위험: 일부 회사·통신사 네트워크에서 직접 연결이 막히면 유료 중계가 필요 → 그 경우 "연결 안 됨" 안내.
- 방 코드(6자리) 또는 초대 링크.
- 방장 브라우저가 모든 계산, 손님은 입력만 보내고 상태를 받아 그림.
- 협동 규칙 [제안]: 경험치 같이 받음(레벨업 카드는 각자), 칩·아이템 보상은 각자 따로, 동료 곁 3초 서 있으면 부활(둘 다 쓰러지면 끝), 2인일 때 적 체력 ×1.6·수 ×1.4·보스 체력 ×1.7(조정), 카메라는 각자, 둘 사이 거리 제한.
- 배속은 방장이 정함 [제안].

## 9. 작업 순서

새로 짜는 코드는 처음부터 "플레이어 여러 명"을 전제로 짬 (나중에 협동을 붙일 때 다시 짜지 않게).

| 단계 | 내용 | 끝 기준 |
|---|---|---|
| 1 | **조작 전환**: 트윈스틱(마우스·가상 스틱 2개), 주무기·보조무기 소켓, 무기 12종 조준형 | 싱글로 한 챕터 플레이 가능 |
| 2 | **소켓·성장 재구성**: 소켓 8칸·소켓 레벨, 레벨업 카드 재편, 아이템 등급·전설/신화 능력, 칩, 태그·시너지 | 빌드에 따라 전투가 달라짐 |
| 3 | **판 구조**: 갈림길 지도, 처치 수 전투방, 상점·리퍼닥·이벤트·엘리트, 보상 | 챕터 1을 방 단위로 끝까지 |
| 4 | **캐릭터 1명 + 외형**, 판 밖 해금 개편, 클리닉 약화, 저장 데이터 이전 | 아지트에서 외형·시작 주무기 고르고 시작 |
| 5 | **게임 로직 분리** (GameScene 6,133줄), 플레이어 배열, 시드 무작위 | 화면 없이도 판이 돌고 기존과 같게 플레이 |
| 6 | **한 화면 2인**으로 협동 규칙 검증 | 둘이서 챕터 1 클리어 |
| 7 | **온라인 2인** (방장 방식, Supabase 신호 교환) | PC 두 대로 같은 판 진행 |
| 8 | 밸런스·플레이테스트, 배포처별 확인 | 사용자 요청 시 배포 |

- 판 구조(3)를 캐릭터(4)보다 앞에 둔 이유: 캐릭터 그림을 아트 세션이 만드는 동안 진행할 수 있어서.

## 10. 남은 질문

1. 사이버웨어 레벨도 소켓 레벨로 할지 (제안: 예)
2. 신화 등급 무기의 능력: 전설 1 + 신화 1 / 신화만 (제안: 둘 다)
3. 사이버웨어·장비의 전설·신화 등급에 능력을 붙일지 (제안: 수치만)
4. 챕터당 방 수 (제안 10~12)
5. 주·보조무기 나눔 (3절) — 1단계에서 플레이로 검증
