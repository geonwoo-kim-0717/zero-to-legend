# Zero to Legend 개편 설계

뱀서라이크(시간 생존 + 자동 공격)에서 **트윈스틱 로그라이트 + 2인 협동**으로 바꾸는 설계.
참고: 사용자가 공유한 ChatGPT 대화("로그라이크 멀티플레이 전환")와 지금 코드(Phaser 3 + TypeScript, 웹).

표시: **[확정]** 사용자가 정함 · **[제안]** 확인 필요 · **[질문]** 아직 정해야 함

배포: 개편 작업은 별도 브랜치에서. **사용자가 요청할 때까지 배포하지 않음** [확정]. 지금 버전은 main에 그대로.

## 2. 조작 (트윈스틱)

**조작 개편 [확정]** (1단계 뒤 플레이 피드백)
- 주무기: **자동 발사**. PC는 커서 방향, 모바일은 가장 가까운 적. 사거리(fireRange) 안에 적이 있을 때만 쏨
- 보조무기: 화면 오른쪽 아래 버튼(둘레에 재사용 대기 표시). 무기마다 쓰는 법이 다름 (weapons.json `use`)
  - 누르기(tap): EMP 필드, 해킹 드론, 마이크로 미사일
  - 끌어 놓기(drag): 플라즈마 유탄, 포탑 배치, 근접 지뢰 — 버튼에서 끌어 놓은 자리에. 짧게 누르면 가장 가까운 적 자리
  - PC: 오른쪽 클릭·E = 커서 자리 (버튼을 마우스로 끌어도 됨)
- 이동: WASD / 모바일은 버튼이 아닌 곳을 누르고 끄는 스틱 (조준 스틱 없앰)
- 대시: Space / Shift / 버튼, OS 능력: Q / 버튼

## 3. 무기: 주무기 6 + 보조무기 6

기존 12종을 둘로 나눔. 커서 방향으로 발사.

| 주무기 (왼쪽 클릭) | 트윈스틱으로 |
|---|---|
| 스마트 피스톨 | 커서 방향 연사, 약한 유도 |
| 스캐터 샷건 | 커서 방향 산탄, 넉백 |
| 레일건 | 커서 방향 충전 관통 빔 |
| 맨티스 블레이드 | 커서 방향 근접 베기 |
| 모노와이어 | 커서 방향 채찍, 맞은 적 1초 아군화 |
| 아크 코일 | 커서 쪽 첫 적에게 번개 → 연쇄 |

| 보조무기 (오른쪽 클릭) | 트윈스틱으로 |
|---|---|
| 플라즈마 유탄 | 커서 위치에 던져 범위 폭발 |
| 마이크로 미사일 | 커서 근처 적에게 유도 미사일 일제 발사 |
| 근접 지뢰 | 커서 위치에 지뢰 설치 |
| 포탑 배치 | 커서 위치에 포탑 설치 |
| 해킹 드론 | 드론 발사 → 일정 시간 주위를 돌며 공격 (자동 공격 유지) |
| EMP 필드 | 커서 위치 또는 자기 주변 감속 전자기장 (자동 피해 유지) |

**[제안]** 주·보조 나눔은 위와 같이 하고 1단계에서 플레이로 검증.

## 5. 성장 시스템 [확정]

원칙: **아이템은 "무엇을 쓸지", 레벨업 카드는 "얼마나 강하게".**

### 5-1. 판 안: 강화 (레벨업 카드)
- 레벨업 카드는 **장착한 것만 강화**. 새 아이템은 카드로 나오지 않음. [확정 1A]
- **레벨은 소켓에 붙음** (무기 소켓 Lv1~8, 장비 소켓 Lv1~5). 아이템을 바꿔 끼워도 소켓 레벨은 그대로 → 새 아이템도 같은 레벨로 시작. [확정 1A, 2A]
- 사이버웨어도 카드로 레벨을 올림. [확정 4C]
  - **[질문]** 사이버웨어도 "소켓 레벨"(바꿔 끼워도 유지)로 할지, 사이버웨어 자체 레벨로 할지. 제안: 다른 소켓과 같이 소켓 레벨.
- 카드 종류 [제안]: 소켓 강화 카드(주무기·보조무기·사이버웨어·장비), 능력치 카드(체력·이동·피해 등), 특수 카드(시너지를 돕는 효과).

### 5-2. 판 안: 빌드 (아이템)
- 얻는 곳: 방 보상(3개 중 1개), 상점, 엘리트·보스 보상. 소켓이 차 있으면 바꿀지 선택.
- **아이템 등급**: 일반·희귀·영웅·전설·신화. 등급이 높을수록 기본 성능이 높음. [확정 3]
- **전설·신화 능력은 아이템 등급에 딸려 옴**: 전설 등급 무기를 얻으면 그 무기의 전설 능력 중 하나가 무작위로 붙어 있음, 신화 등급이면 신화 능력. [확정 3]
  - 지금처럼 레벨업 카드로 능력을 얻는 방식은 없어짐.
  - **신화 등급 무기는 신화 능력 1개만** [확정]. 그 무기가 들어간 **시너지가 발동하면 그 무기의 전설 능력도 추가로 얻음** [확정, 해석 확인 필요: '시너지 효과 해체시'를 '시너지가 열리면'으로 이해함].
  - **[질문]** 사이버웨어·장비에도 전설·신화 등급과 능력을 둘지. 제안: 등급은 두되 능력은 무기만, 사이버웨어·장비는 등급만큼 수치가 높아짐.
- **리퍼닥 조우 이벤트** [확정 3, 4C]: OS 교체, 사이버웨어 설치·교체, 아이템 등급 올리기(판 안 재화 사용).

### 5-3. 재화 [확정 5A]
- **판 안 재화(가칭 "칩")**: 처치·방 보상으로 얻고 상점·리퍼닥에서 씀. 판이 끝나면 사라짐.
- **크레딧**: 판이 끝나면 쌓이고 아지트에서 씀.

### 5-4. 판 밖 성장 [확정 6A]
- **무기·장비는 처음부터 모두 해금** (판 안 보상에 다 나옴).
- **해금 대상**: 사이버웨어, OS, 시작 주무기 선택, 외형(색·성별·의상).
  - 지금의 러너 해금은 없어지고 이 해금으로 바뀜.

### 5-4-1. OS 해금·레벨 [확정]
- **OS는 상자 뽑기로 해금**: 상자 1번에 무작위 OS 1종. **10회 뽑기** 있음.
- 같은 OS를 또 뽑으면 그 OS의 개수가 쌓이고, 개수로 **OS 레벨업** (최대 5레벨).
  - 필요 개수: **레벨마다 새로 1, 2, 4, 8, 12개** (1레벨 해금 1개 … 5레벨까지 **합계 27개**) [확정].
- **OS 레벨마다 능력이 1줄씩 추가**: 1레벨 능력 1줄 … 5레벨 능력 5줄.
  - 예 (뉴럴 오버클럭) [제안]: 1줄 Q로 공격속도 2배·적 속도 0.5배 / 2줄 지속 +2초 / 3줄 발동 중 처치하면 지속 연장 / 4줄 끝날 때 주변 적 감속 폭발 / 5줄 발동 중 보조무기 재사용 대기 없음.
- 판 안에서는 리퍼닥에서 **해금한 OS 중에서** 바꿔 낌. 그 OS의 레벨(능력 줄 수)은 아지트에서 모은 레벨 그대로.
- **10회 뽑기 = 9회 값** [확정].
- **5레벨 OS가 또 나오면 크레딧 일부 환급** [확정]. 제안: 상자 값의 1/3(100).
- **기본 OS 1종을 처음부터 줌** [확정]: 레벨 1 고정, 효과는 아주 약함(예: 대시 재사용 대기 -10%). 뽑기에는 안 나옴 [제안].
- **OS 종류 6~8종** [확정]. 제안 8종 = 기본 1 + 지금 특수 능력 4 + 새로 3.
  - 지금 특수 능력 4종(뉴럴 오버클럭·광전사·광학 위장·궤도 폭격)의 **현재 효과는 4~5레벨 수준** [확정] → 1~3레벨은 그보다 약한 버전으로 나눔.
  - 새 OS 3종 [제안]: 가디언(보호막·피해 감소, 방어 태그), 택티컬(표식·드론·포탑 강화, 기계 태그), 해커(감전·교란·아군화, 해킹·전기 태그).
- **상자 확률**: 뽑기에 나오는 OS 7종 같은 확률(각 1/7) [제안]. 확률은 화면에 공개(여러 플랫폼·국가 규정 대비). 크레딧 전용, 실제 돈 결제 없음 [제안].

#### 상자 값 (경제 확인 후 임시 설정) [임의 설정, 플레이로 조정]
지금 크레딧 수입 (`meta.json` credits):
- 처치 1명 0.25, 1초 0.083(1분 5), 중간보스 30, 챕터 보스 75, 최종 승리 250
- 대략 한 판 수입: 짧은 판(10분, 처치 1,000) 약 300 / 중간(20분, 처치 2,500) 약 800 / 완주(30분+, 처치 4,000) 약 1,600

지금 크레딧을 쓰는 곳: 특수 능력 해금 1,000×4, 블랙마켓 무기 3,000~5,000×6(합 23,000), 클리닉(합 약 2만).
→ 개편 후 무기는 모두 해금이라 **블랙마켓 23,000이 사라지고, OS 상자가 주된 지출**이 됨.

| 항목 | 임시 값 | 근거 |
|---|---|---|
| 상자 1회 | **300** | 중간 판 한 번에 2~3회 |
| 10회 | **2,700** (9회 값) | 중간 판 3~4번 |
| 5레벨 중복 환급 | 100 | 1회 값의 1/3 |
| OS 1종 5레벨까지 | 27개 = 평균 약 189회 (7종 중 1/7) | 모든 OS 최대까지 189회 ≈ 57,000 크레딧 |

- 모든 OS를 최대까지 키우는 데 중간 판 70판 안팎. 해금(1개씩)은 초반 몇 판 안에 대부분 됨.
- 클리닉을 약하게 바꾸면서 값도 함께 조정 (4단계).
- **클리닉 영구 능력치는 지금보다 약하게** 유지. [확정]
  - **[제안]** 단계별 효과를 지금의 절반 정도로 하고, 최대 단계 수 유지. 수치는 2단계 끝날 때 플레이로 조정.

### 5-5. 시너지 [확정 7A]: 태그 단계 + 이름 붙은 조합
- **태그 6개로 시작 [제안 목록]**: 전기, 폭발, 정밀(관통·치명), 근접, 기계(드론·포탑), 해킹(아군화·교란).
- 무기·사이버웨어·장비·OS 모두 태그를 가짐. 8칸에서 같은 태그가 **2·3·4개** 모이면 단계별 효과.
  - 예: 전기 2 → 감전 피해 증가, 전기 3 → 감전된 적이 죽을 때 연쇄 번개, 전기 4 → 연쇄 횟수 +2
- **이름 붙은 조합 약 10개 [제안]**. 예:
  - 해킹 드론 + 신경 사이버웨어 → 드론이 해킹한 적이 잠깐 아군
  - EMP 필드 + 방어 장비(쉴드) → 쉴드가 깨지면 EMP 폭발
  - 레일건 + 안구 사이버웨어 → 표식된 적에게 관통 피해 증가
  - 포탑 + 전술 장비(드론 도킹) → 포탑 수 +1
- **[제안] 처음 만들 양**: OS 4(기존 특수 능력 확장), 사이버웨어 9(부위별 3), 장비 8, 이름 붙은 조합 10.

## 6. 판 구조 (경로·방 선택)

챕터 3개(하층가 슬럼·인더스트리얼·타워)와 보스 6종 유지. 챕터마다 갈림길 지도.

```
시작 → [전투] → (갈림길) [전투]/[이벤트] → [상점]/[엘리트] → [전투] → [리퍼닥] → [중간보스]
     → [전투]/[보물] → [엘리트] → [상점] → [보스] → 다음 챕터
```

| 방 | 내용 | 기존 자산 |
|---|---|---|
| 전투 | **처치 수를 채우면 클리어** [확정] | 지금 적·스폰 디렉터 |
| 엘리트 | 블랙 실드 분대·카운터 몬스터 (개편) | 블랙 실드 습격, 카운터 |
| 상점 | 칩으로 아이템·회복 구매 | 블랙마켓 |
| 이벤트 | 진의 의뢰·선택지 (개편) | 진 대화 |

## 8-1. 2단계 결정 [확정]
- **전설·신화 등급 무기를 얻으면 그 등급의 능력 중 하나를 골라 붙임** (무작위 아님) [확정].
- **능력에 따라 무기 태그가 추가됨** (예: 샷건 드래곤 브레스 → 폭발, 스마트 피스톨 연쇄 사격 → 전기) [확정]. 능력별 추가 태그는 편집 페이지 "무기 능력" 탭에서 고침.
- **챕터가 바뀌어도 빌드를 한 판 내내 이어감** (지금의 챕터 전환 초기화·능력 1~2개 고르기는 없앰). 적은 챕터마다 강해짐.
- **3단계(방 구조) 전 임시 아이템 획득: 보급 상자** — 일정 처치 수마다, 엘리트·보스 처치 때. 열면 아이템 3개 중 1개.
- **사이버웨어 9·장비 8·시너지 표는 편집 페이지(OS 설계실)에 추가**해 사용자가 고치고, 코드는 그동안 소켓 구조부터 진행.
- **선택 포기 버튼** (보급 상자·레벨업 카드): 칩을 받음 (game.json supply.skipChips, 상자 최소 등급별) [확정].
- **2-2 구현**: 사이버웨어 9·장비 8 효과, 태그 단계(2/3/4)·조합 10종 — src/systems/Loadout.ts가 장착한 것에서 켜진 효과(hook)를 모음. 사이버웨어·장비 레벨도 소켓 레벨(레벨업 카드로 올림).

| 1 | **조작 전환**: 트윈스틱(마우스·가상 스틱 2개), 주무기·보조무기 소켓, 무기 12종 조준형 | 싱글로 한 챕터 플레이 가능 |
| 2 | **소켓·성장 재구성**: 소켓 8칸·소켓 레벨, 레벨업 카드 재편, 아이템 등급·전설/신화 능력, 칩, 태그·시너지 | 빌드에 따라 전투가 달라짐 |
| 3 | **판 구조**: 갈림길 지도, 처치 수 전투방, 상점·리퍼닥·이벤트·엘리트, 보상 | 챕터 1을 방 단위로 끝까지 |
| 4 | **캐릭터 1명 + 외형**, 판 밖 해금 개편, 클리닉 약화, 저장 데이터 이전 | 아지트에서 외형·시작 주무기 고르고 시작 |
